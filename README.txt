WORK HOURS PWA

Files:
- index.html
- manifest.json
- sw.js
- icon.svg

Important: open index.html directly to preview it, but for iPhone installation/offline mode,
the folder needs to be hosted over HTTPS (for example GitHub Pages, Netlify, or another web host).

On iPhone:
1. Open the hosted URL in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Open Work Hours from the new icon.

Entries are saved locally in the browser on that device.
Use Export CSV periodically for backup.
